# Starter package scope (working proposal)

**Suggested project fee: Rp2.000.000.** This is a narrow starter package based on a reusable template, not a bespoke redesign.

## Included

- One responsive static company profile page with up to five main sections.
- Fixed template layout and existing reusable components.
- Client brand name, logo or text wordmark, one supported color palette, and one font pairing.
- Client-supplied copy and images placed in existing content slots.
- Existing anchor navigation, WhatsApp and Instagram links, and basic SEO metadata.
- One deployment and one consolidated revision round for text, image, and supported brand-token changes.
- Successful production build and handover notes.

This ALDI Suits demo has five top-level sections: hero; collection and event prices; wedding packages; custom-made, process and rental terms; contact.

## Excluded

- New or rearranged layouts, custom page designs, or more than five main sections.
- Copywriting, translation, photography, logo design, or paid assets.
- CMS/admin panel, database, booking calendar, payment flow, accounts, form processing, or automated messaging.
- Domain registration, business email, paid third-party services, ongoing content changes, and recurring maintenance.
- Features or revisions beyond the agreed included round.

## Change requests

Estimate and approve out-of-scope requests before starting. Quote additional sections, layout changes, copywriting, integrations, and ongoing support separately. Content revisions are separate from bug fixes. Agree any bug-fix warranty period and payment timing in the client proposal.

Confirm final handover, template reuse, source-code access, and client asset rights before work begins.
