# ALDI Suits - Starter Company Profile

Starter company profile for ALDI Suits, a suit rental and custom-made suit business in Waru, Sidoarjo. Built with React, Vite, JavaScript, Tailwind CSS 4, and Lucide React.

## Run locally

Requires Node.js 18 or newer. Run npm install, then npm run dev. Use npm run build to create a production build and npm run preview to preview it.

Product, price, contact, and rental process content is centralized in src/data.js. Reusable presentation components live in src/components. The site is static and has no CMS or admin panel; content edits require updating project files and redeploying.
